# Miss Glamour Empire International

A luxurious, modern, and mobile-first website for a premium modeling and pageantry platform.

## 🌐 Live Demo
You can see the live website here: **[https://Tidzie.github.io/miss-glamour/](https://Tidzie.github.io/miss-glamour/)**

## ✨ Features
- **Luxury Fashion Editorial Aesthetic**: Elegant gold accents and premium typography.
- **Dynamic Voting System**: Contestant cards with live counts and leaderboard.
- **Empowering Registration**: Forms for Models, Parents, and Sponsors.
- **Cinematic Animations**: Smooth transitions and scroll-triggered effects.
- **Responsive**: Fully optimized for mobile, tablet, and desktop.

## 🛠️ Tech Stack
- **React + Vite**
- **Tailwind CSS**
- **Framer Motion**
- **Lucide React**

## 🚀 Deployment
This project is deployed using GitHub Pages. To deploy updates:
```bash
npm run deploy
```
